# 一键双击启动器 设计文档

日期：2026-07-16

## 目标

让三个自动化脚本（`scaffold_dirs.py` / `run_crop.py` / `run_train_distill.py`）可以**双击运行**，
免去手动「开终端 → `conda activate AR` → `cd` 项目 → `python xxx.py`」这一串操作。

## 方案

在项目根目录新增三个 Windows 批处理启动器（`.bat`），双击即用：

| 启动器 | 运行的脚本 |
|--------|-----------|
| `建目录.bat` | `scaffold_dirs.py` |
| `切片.bat` | `run_crop.py` |
| `合并训练.bat` | `run_train_distill.py` |

每个 `.bat` 依次完成：切到脚本所在目录 → 激活 `AR` 环境 → 运行脚本 → 结尾 `pause` 停住窗口。

## 关键决策

1. **路径自适应**：用 `%~dp0`（`.bat` 自身所在目录）作为项目根目录，不写死绝对路径。
   项目整体移动到别的盘/路径也无需修改，只要 `.bat` 与脚本放在一起即可。

2. **conda 环境**：固定激活 `AR`。前置条件——普通 cmd 里可直接调用 `conda`（conda 已在 PATH 中，已确认）。

3. **`--frames` 选项**：`切片.bat` 和 `合并训练.bat` 启动后在窗口里问一句
   「是否切帧格式？(y/N)」，回车默认视频 clip，输入 `y` 追加 `--frames`。
   `建目录.bat` 无此选项，直接运行。

4. **跑完窗口停住**：结尾 `pause`，正常结束或报错窗口都不关，便于查看输出。

## 明确不做

- 不做图形界面（GUI）。
- 不做参数记忆 / 配置持久化。
- 不改动现有三个 `.py` 脚本的任何一行代码，纯新增启动器。
