# 兔子行為識別模型提升方案

## 現狀問題

- 訓練數據主要來自手持／網路影片，部署在固定攝影機畫面——視角、光線、背景完全不同，模型到現場「水土不服」
- 當前模型（RepViT-M1）是為低功耗設備設計的輕量級架構，PC 端算力充裕，但模型能力未充分利用

---

## 現有數據分布

| 類別           | 訓練集  | 驗證集 | 合計   |
| ------------ | ---- | --- | ---- |
| Eating（進食）   | 1229 | 300 | 1529 |
| Moving（移動）   | 756  | 186 | 942  |
| Resting（休息）  | 899  | 220 | 1119 |
| Drinking（飲水） | 984  | 239 | 1223 |

四類整體量級相近，但 Moving 偏少，且所有類別現有數據以手持／網路影片為主，與攝影機實景有明顯差距。

---

## 改進方向

### 一、數據補充

- 從 hkbr 部署點回收真實攝影機影片，重點補充 Eating 和 Drinking 兩類
- 目標：兩類各追加約 800 條真實攝影機數據
- 同時對現有網路影片數據加入攝影機風格增強（運動模糊、解析度降低、色彩偏移），縮小與實景的差距

### 二、模型升級

- 將模型從 RepViT-M1（~5M 參數）升級至 RepViT-M1.5（~13M 參數），同屬一個架構家族，代碼改動小
- 

---

## 任務拆解與時間線

### 第一週：模型改造 + 數據回收啟動

| 任務                                        | 預計完成   |
| ----------------------------------------- | ------ |
| 修改訓練代碼，支援 RepViT-M1.5 骨架；對現有網路影片加入攝影機風格增強 | 第1–2 天 |
| 在現有數據上跑基線訓練（M1.5，無新數據）                    | 第2–5 天 |
| hkbr 部署點回撈攝影機影片并標註（每个动作新增500条样本）          | 第1–5 天 |

### 第二週：數據增強 + 新數據標註

| 任務                               | 預計完成  |
| -------------------------------- | ----- |
| 合併新舊數據，重新訓練最終版模型                 | 第3-5天 |
| hkbr 部署點回撈攝影機影片并標註（每个动作新增300条样本） | 第1-3天 |
| 在 hkbr 攝影機畫面上驗證新模型表現             | 第4-5天 |

---

## 資源需求

1. hkbr 部署點的攝影機影片回撈
2. Eating／Drinking 類別的人工標註或半自動標註

---

## 後續

PC 端模型穩定後，可用其作為教師模型，蒸餾出輕量版本部署至低功耗設備（SoC），無需重新採集數據。
